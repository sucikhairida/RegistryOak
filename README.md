# RegistryOak

RegistryOak is a distributed event-driven processing platform for dynamic configuration management and scalable data synchronization between multiple servers.

With RegistryOak, you get a lightweight tool that stays out of your way.

**What you get**

- RegistryOak is a distributed event-driven
- processing platform for dynamic configuration
- management and scalable data synchronization

## Key Features

- RegistryOak is a distributed event-driven
- processing platform for dynamic configuration
- management and scalable data synchronization

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/RegistryOak.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

RegistryOak is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
